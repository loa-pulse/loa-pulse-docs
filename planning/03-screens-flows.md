# 03. 화면 구성과 사용자 흐름

## 사이트맵

```
LoaPulse
├── 메인 (/)                       비로그인 가능
│   ├── 급등락 랭킹 TOP 10 (F5)
│   └── 관심 아이템 (F7, 로그인 시)
├── 시세 목록 (/items)             비로그인 가능
│   └── 카테고리 탭 + 검색 (F1)
├── 아이템 상세 (/items/:id)       비로그인 가능
│   ├── 현재가, 등락률, 갱신 시각 (F2)
│   ├── 차트 (F3)
│   └── [알림 설정] [관심 등록] 버튼
├── 내 알림 (/alerts)              로그인 필요
│   ├── 등록한 알림 목록 (F8)
│   └── 받은 알림 내역 (F10)
├── 설정 (/settings)               로그인 필요
│   └── 급변동 알림 구독 on/off (F11), DM 수신 테스트
└── 서비스 상태 (/status)          비로그인 가능 (F12)
```

화면은 6개다. **조회 기능은 모두 비로그인으로 연다.** 면접관이 로그인 없이 바로 둘러볼 수 있어야 하기 때문이다.

## 주요 화면 와이어프레임

### 메인

```
┌───────────────────────────────────────────────────┐
│ LoaPulse     시세  내 알림  상태    [디스코드 로그인] │
├───────────────────────────────────────────────────┤
│  실시간 급등락 (최근 1시간)          ● 실시간 연결 중 │
│  ┌─ 상승 TOP 10 ─────────┐ ┌─ 하락 TOP 10 ─────────┐ │
│  │ 1. 운명의 파괴석 +12.3% │ │ 1. 유물 각인서A -8.1%  │ │
│  │ 2. ...                 │ │ 2. ...                 │ │
│  └────────────────────────┘ └────────────────────────┘ │
│  내 관심 아이템 (로그인 시)                            │
│  [파괴석 152G ▲2%] [수호석 31G ▼1%] [+ 추가]           │
└───────────────────────────────────────────────────┘
```

### 아이템 상세

```
┌───────────────────────────────────────────────────┐
│ ← 운명의 파괴석                     [☆ 관심] [🔔 알림] │
│                                                     │
│  152 G   ▲ 3 (+2.0%) 전일 대비                       │
│  마지막 갱신: 12초 전  ● 실시간                      │
│                                                     │
│  [오늘] [2주]                                       │
│  ┌───────────────────────────────────────────────┐ │
│  │                 차트                    ╱╲      │ │
│  │         ╱╲   ╱╲╱  ╲╱                  ╱  ╲     │ │
│  └───────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────┘
```

### 알림 설정 모달 (상세 화면의 🔔 버튼)

```
┌─ 운명의 파괴석 알림 ─────────────────┐
│ 현재가 152 G                         │
│ 조건  (●) 이하가 되면  ( ) 이상이 되면 │
│ 기준가 [ 140 ] G                     │
│ 받을 곳  ☑ 디스코드 DM  ☑ 웹 알림    │
│                  [취소]  [등록]      │
└──────────────────────────────────────┘
```

> 와이어프레임의 아이템 이름과 가격은 예시다.

## 사용자 흐름

### 흐름 1. 목표가 알림 (S1 메인 시나리오)

```
메인/검색 → 아이템 상세 → 차트로 추이 확인 → 🔔 알림 클릭
  → (비로그인이면) 디스코드 로그인 → 상세 화면으로 복귀
  → 기준가 입력 후 등록 → "등록됨" 토스트
  ... 시간 경과 ...
  → 조건 충족 → 디스코드 DM 수신 ("파괴석이 139G가 됐어요" + 상세 링크)
  → 링크 클릭 → 상세 화면에서 현재가 확인 → 게임에서 구매
  → 알림은 '발송 완료' 상태로 전환 (재사용하려면 다시 켠다)
```

### 흐름 2. 급등락 확인 (S3 보조 시나리오)

```
메인 진입 → 랭킹이 실시간으로 갱신되는 것을 확인
  → 관심 가는 아이템 클릭 → 상세 차트에서 급등 시점 확인
(선택) 설정에서 급변동 알림 구독 → 이후 급변동 시 DM 수신
```

### 흐름 3. 첫 로그인

```
로그인 버튼 아래 고지 확인 ("알림 수신을 위해 LoaPulse 디스코드 서버에 참여합니다")
  → [디스코드 로그인] → 디스코드 권한 동의 (identify, guilds.join)
  → 복귀와 동시에 LoaPulse 서버 자동 참여
  → 최초 1회 [테스트 DM 보내기]로 수신 확인
  → DM 실패 시 원인별 안내 배너 표시
```

서버 참여와 DM 실패 처리의 세부 규칙은 [04-policies.md](04-policies.md) 4.4를 따른다.
