# 01. 로스트아크 도메인 용어집

> 로스트아크를 플레이하지 않은 개발자를 위한 최소한의 용어 정리.
> 아이템 이름과 세부 수치는 게임 업데이트로 자주 바뀌므로, **M0 사전 조사에서 실제 API 응답으로 검증**한다.

## 경제 기본

| 용어 | 설명 | 서비스에서의 의미 |
|---|---|---|
| 골드 | 게임 내 주요 화폐. 유저 간 거래에 쓰인다 | 모든 시세의 단위 (G) |
| 거래소 | 같은 아이템을 가격순으로 사고파는 곳. 주식 호가창과 비슷하다 | **MVP 수집 대상** |
| 경매장 | 옵션이 제각각인 아이템(보석, 장신구)을 거래하는 곳. 매물마다 가격이 다르다 | MVP 제외. 시세를 어떻게 정의할지부터 별도 기획 필요 |
| 최저가 | 거래소에 올라온 매물 중 가장 싼 가격 | 서비스의 "현재가" 기준 |
| 묶음 단위 | 일부 재료는 10개, 100개 같은 묶음으로 거래된다 | 개당 가격 환산이 필요한지 M0에서 확인 |
| 귀속 | 거래할 수 없는 상태의 아이템 | 수집 대상에서 제외 |

## 성장과 소비

| 용어 | 설명 | 서비스에서의 의미 |
|---|---|---|
| 아이템 레벨 | 캐릭터 장비 수준을 나타내는 수치. 높을수록 상위 콘텐츠에 입장 가능 | 유저가 재련하는 이유 |
| 재련 | 장비를 강화해 아이템 레벨을 올리는 행위. 확률형이며 재료를 대량으로 소모한다 | **메인 페르소나의 핵심 행동**. 골드가 가장 많이 쓰이는 곳 |
| 재련 재료 | 재련에 쓰는 재료 묶음. 대표적으로 파괴석(무기용), 수호석(방어구용), 돌파석(확률 보조), 융화 재료 | 거래량이 가장 많고 시세 변동에 민감한 아이템군 |
| 티어 | 장비와 재료의 세대 구분. 상위 티어 재료가 현재 주력 거래 대상이다 | 수집 우선순위 판단 기준 |
| 각인서 | 캐릭터 능력(각인)을 강화하는 소모 아이템. 등급이 높을수록 비싸다 | 고가 아이템. 가격 변동 폭이 큼 |
| 보석 | 스킬을 강화하는 아이템. 경매장에서 거래된다 | 로드맵 첫 확장 후보 |
| 생활 재료 | 채집, 채광, 낚시 등 생활 콘텐츠로 얻는 재료 | 판매 타이밍(S2)에 관심이 많은 아이템군 |

## 운영

| 용어 | 설명 | 서비스에서의 의미 |
|---|---|---|
| 정기 점검 | 주 1회 진행하는 서버 점검. 이 시간에는 거래가 멈춘다 | 점검 중 배너 표시, 수집 일시 중단 |
| 패치 / 업데이트 | 콘텐츠 추가나 밸런스 변경 | 시세가 크게 출렁이는 시점. 보조 시나리오(S3)의 배경 |
| 이벤트 | 기간 한정으로 재료를 지급하거나 재련 확률을 높이는 행사 | 재료 시세 급변동의 주요 원인 |

## Open API

| 용어 | 설명 |
|---|---|
| 로스트아크 Open API | 스마일게이트가 제공하는 공식 API. 개발자 포털에서 키를 발급받는다 |
| Markets | 거래소 관련 API. 아이템 검색, 현재가, 최근 2주 일별 시세 등 |
| Auctions | 경매장 관련 API. 검색 조건이 복잡하다 (MVP 미사용) |
| 호출 제한 | **키 하나당 분당 100회**. 응답 헤더로 남은 횟수와 초기화 시점을 알려준다 |
