# 00. 개요

> LoaPulse 기획 문서 · 작성일 2026-10-07

## 한 줄 소개

로스트아크 거래소 시세를 실시간으로 추적하고, 원하는 가격이 되면 디스코드로 알려주는 서비스

## 프로젝트 목표

| 구분 | 내용 |
|---|---|
| 1차 목표 | 백엔드 포트폴리오. 실시간 시세 파이프라인과 알림 시스템을 설계하고, 개선 결과를 수치로 증명한다 |
| 비목표 | 실사용자 확보, 수익화 (스마일게이트 Open API 약관 제약도 있음) |
| 기간 | 15주(약 3.5개월), 주 10~15시간 |
| 개발 형태 | 1인 풀스택. 비중은 백엔드 7~8 : 프론트엔드 2~3 |

## 기술 스토리 방향

- **메인**: 수집부터 실시간 푸시까지 이어지는 시세 파이프라인. 특히 호출 제한 안에서 데이터 신선도를 최대화하는 수집 스케줄러
  - 로스트아크 Open API는 WebSocket 스트림을 제공하지 않으므로, 수집 방식은 반드시 pull(분당 100회 제한 안에서 polling)이 된다.
- **서브**: 알림. 브로드캐스트(급변동)와 사용자별 조건(목표가) 알림
- **로드맵**: 시계열 데이터 장기 저장과 조회 최적화

## 대상 사용자

### 메인 페르소나: 재련하는 유저 "강화중"

- 캐릭터를 강화하려고 재련 재료를 대량으로 산다.
- 쌀 때 사고 싶지만 시세를 계속 들여다볼 시간은 없다.
- 필요한 것: 시세 추이 확인, 목표가 알림

### 보조 페르소나: 패치 직후 유저 "눈치파"

- 업데이트 직후 무엇이 오르고 내리는지 빠르게 알고 싶다.
- 필요한 것: 실시간 급등락 랭킹, 급변동 알림

## 핵심 시나리오

| ID | 시나리오 | 비중 |
|---|---|---|
| S1 | 구매 타이밍 판단: "파괴석을 대량으로 사야 하는데, 쌀 때 알려줘" | 메인 |
| S2 | 판매 타이밍 판단: "내 재료가 오를 때 팔고 싶다" | S1에 흡수 (알림 조건 이상/이하로 해결) |
| S3 | 시장 흐름 파악: "패치 직후 지금 뭐가 급등하고 있지?" | 보조 |

## 범위

| 포함 (MVP) | 제외 (로드맵) |
|---|---|
| 거래소 아이템 (재련 재료, 각인서, 생활 재료 등) | 경매장 (보석이 첫 확장 후보) |
| 디스코드 로그인 | 시계열 장기 분석, 통계 |
| 목표가 알림 (이상/이하), 디스코드 DM과 웹 인앱 | 텔레그램 등 다른 알림 채널 |
| 실시간 시세와 급등락 랭킹 | 커뮤니티, 재련 비용 계산기 |
