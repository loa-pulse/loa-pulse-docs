# 02. 기능 정의와 우선순위

## 우선순위 기준

| 등급 | 의미 |
|---|---|
| P0 | MVP 필수. 없으면 핵심 시나리오가 성립하지 않는다 |
| P1 | MVP 기간 안에 하면 좋다. 여유에 따라 진행한다 |
| P2 | 로드맵 |

포트폴리오가 목적이므로, 각 기능이 어떤 백엔드 문제와 연결되는지 함께 적는다.

## 시세 조회

| ID | 기능 | 설명 | 우선순위 | 연결되는 백엔드 문제 |
|---|---|---|---|---|
| F1 | 아이템 목록, 검색 | 카테고리별(재련 재료, 각인서, 생활 재료 등) 목록과 이름 검색 | P0 | 캐싱 |
| F2 | 아이템 상세 | 현재 최저가, 전일 대비 등락률, **마지막 갱신 시각** | P0 | 데이터 신선도 |
| F3 | 시세 차트 | 오늘 분 단위 추이, 최근 2주 일별 추이 | P0 | 시계열 저장 |
| F4 | 실시간 반영 | 보고 있는 화면의 시세가 새로고침 없이 갱신된다 | P0 | 실시간 푸시 (SSE) |
| F5 | 급등락 랭킹 | 최근 1시간 기준 상승/하락 TOP 10, 실시간 갱신 | P0 | 집계, 브로드캐스트 |

## 로드맵 (P2)

- 경매장 보석 시세
- 장기 시세 차트 (월, 연 단위)와 기간별 통계
- 재련 비용 계산기 (시세 연동)
- 반복 발송 목표가 알림 (쿨다운, 히스테리시스 포함)
- 텔레그램 등 다른 알림 채널

## 기획 의도

- **F2의 "마지막 갱신 시각"은 일부러 사용자에게 노출한다.** 신선도가 화면에 보이는 지표가 되면, 수집 스케줄러 개선 효과를 화면으로 증명할 수 있다.
- **F7 관심 아이템은 단순 즐겨찾기가 아니라 수집 우선순위의 입력 신호로도 쓴다.** 기획과 백엔드 문제가 이어지는 지점이다. ([04-policies.md](04-policies.md) 4.1 참고)
- **F12 상태 페이지는 실사용자보다 포트폴리오 방문자(면접관)를 위한 기능이다.** P1이지만 일정이 밀려도 끝까지 지킨다. ([05-milestones.md](05-milestones.md) 참고)
