> Figma 디자인을 기준으로 프론트엔드 작업을 커밋 단위로 나눈 계획 · 작성일 2026-11-01

| 지원 범위 | **데스크톱 웹만** 지원한다 (1440px 기준). 모바일과 반응형은 만들지 않는다 |

## 진행 방식

- **커밋 단위**: 한 단위는 한 가지 책임만 다루고, 파일은 5개 이하로 둔다. 테스트는 대상 코드와 같은 단위에 넣는다.
- **폴더 구조**: 도메인별로 `src/features/<도메인>/{api, hooks, components}`를 둔다. 도메인은 market, realtime, auth, alerts, watchlist, status다. 여러 도메인이 함께 쓰는 UI는 `src/components/`에 둔다.
- **디자인 토큰**: Figma 변수 이름이 shadcn 토큰(`color/*`)과 같다. `index.css`에는 `price/*`, `status/*`, `grade/*`, `brand/*`만 더한다. 토큰을 바꿀 때는 Figma와 `index.css`를 같이 바꾼다.
- **API 타입**: 백엔드 OpenAPI가 나오기 전에는 직접 쓴 타입과 MSW 목업으로 개발한다. 목업 데이터는 M0에서 받은 실제 응답([07-api-findings.md](07-api-findings.md))을 따른다. OpenAPI가 나오면 생성 타입으로 바꾼다 (D7).
- **프리뷰 배포**: Vercel 프리뷰 주소에서는 로그인이 되지 않는다. 프리뷰는 MSW 목업으로 화면만 확인한다 (D28).

### 표기 규칙

| 항목 | 규칙 | 예 |
|---|---|---|
| 가격 | 천 단위 쉼표와 ` G`. 평균가처럼 소수가 있으면 소수 첫째 자리까지 | `1,240 G`, `791.6 G` |
| 등락률 | 절댓값을 소수 첫째 자리까지 쓰고 방향은 ▲▼와 색으로 보여준다. 0이면 `–` | `▲ 2.0%`, `– 0.0%` |
| 거래량 | 1만 이상은 `만`, 1억 이상은 `억` 단위로 줄인다 | `124만`, `1.2억`, `9,800` |
| 값 없음 | API가 `null`을 주면 `–` | 수집한 지 1시간이 안 된 1시간 변동률 |
| 상대 시간 (KST) | 1분 미만 `N초 전`, 1시간 미만 `N분 전`, 오늘 `HH:mm`, 그 전 `M월 D일 HH:mm` | `12초 전`, `14:32` |

### 기술

| 항목 | 결정 | 단위 |
|---|---|---|
| 날짜 처리 | 라이브러리 없이 `Intl`만 쓴다. 필요한 것은 KST 표시와 상대 시간뿐이다 | 0-4 |
| 폼 | react-hook-form과 zod. 검증 규칙을 zod 스키마로 따로 두어 테스트한다 | 3-7 |
| 프리뷰 목업 | `VITE_USE_MOCK=true`면 MSW를 켠다. Vercel 프리뷰 환경에만 설정한다 | 1-2 |
| OpenAPI 가져오기 | 백엔드 레포에 커밋한 `openapi.json` ([05-api.md](../design/05-api.md#openapi-전달)) | 1-13 |
| 탭이 숨겨졌을 때 SSE | 10분이 지나면 끊고 다시 보이면 재연결 ([05-api.md](../design/05-api.md#연결)) | 2-5 |
| CSRF | `XSRF-TOKEN` 쿠키를 읽어 `X-XSRF-TOKEN` 헤더로 보낸다 ([05-api.md](../design/05-api.md#csrf)) | 3-6 |
